# Demandes de voix off

Chaque fichier `.txt` ajouté ici lance la génération d'une voix off (workflow « Voix off (Chatterbox) »).
Le studio en ligne prépare ce fichier pour toi. Format :

```
voix: clara
vitesse: 1.0
emotion: 0.5
langue: auto
titre: Ma vidéo
---
Ton script ici…
```

Le résultat (MP3 + WAV) apparaît quelques minutes plus tard dans l'onglet **Releases** du dépôt.
